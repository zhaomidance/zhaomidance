# 🎭 蒙面舞会 · 婚配玩法

多人在线匿名婚配匹配网页，可直接在 QQ 内打开。**纯前端实现，数据存储在 GitHub 仓库，无需后端服务器。**

## 架构

- **前端**：GitHub Pages 静态托管（两个页面）
- **数据存储**：仓库内 `data.json` 文件，通过 GitHub Contents API 读写
- **无需后端、无需信用卡、无需第三方服务**

## 页面

| 页面 | 地址 | 说明 |
|------|------|------|
| 用户页 + 大屏 | https://zhaomidance.github.io/zhaomidance/ | 验票入场、舞会大屏、查配对结果、确认/解除舞伴、投入灵石 |
| 管理后台 | https://zhaomidance.github.io/zhaomidance/admin.html | 录入白名单、系统匹配、灵石/任务/阶段管理 |

## 玩法流程

1. **红娘录入门票**：后台「报名人员录入」按 `二字马甲,门票编号` 每行一人导入（逗号 / 空格 / 顿号 / 竖线 / 制表符等分隔符均可）。
2. **验票入场**：玩家点「我要报名」，填写「二字马甲 + 门票编号」，核对成功后才能填写性别、许愿对象、自我描述，缴纳 999 灵石入场。
3. **系统匹配**：红娘点「系统缘分匹配」，按双方许愿/自述关键词契合度全局贪心配对，大屏展示今夜佳偶。
4. **确认舞伴**：双方各有一次确认按钮，各扣 1314 灵石；双方都确认后关系正式确立。
5. **解除舞伴**：任一方扣 1111 灵石即可解除，双方已投入灵石清零，回到待匹配队列。
6. **灵石共池解锁任务**：双方确认后，各自可投入灵石；两人投入**总和**达到任务解锁值即点亮该任务，进度条实时显示。

## 功能

- ✅ 门票白名单验票，不再尝试获取 QQ 号（QQ 官方禁止普通 H5 网页获取 QQ 账号）
- ✅ 二字马甲为唯一身份主键，本地缓存，回来不用重填
- ✅ 报名弹窗两步式：先验票，再填信息
- ✅ 报名入口与大屏同页：待匹配舞伴按男/女分列展示，实时人数统计
- ✅ **缘分匹配算法**（非骰子）：参考双方"许愿"与对方"自我描述"的关键词契合度，全局贪心配对，支持十几人同时匹配
- ✅ 已匹配区大卡片展示：名字、缘分值、双方许愿、确认状态、共池灵石
- ✅ 大屏阶段：报名中 → 第一次匹配 → 第二次匹配 → 最终匹配（后台可切换）
- ✅ 确认舞伴 1314（双方各自扣费）、解除舞伴 1111
- ✅ 灵石共池按双方总和解锁任务，页内进度条 + 解锁提示
- ✅ 后台任务可设置「解锁灵石数值」，支持添加 / 改值 / 删除 / 标记完成
- ✅ 蒙面舞会装饰：面具水印、飘浮羽毛与烛台、装饰带、四角花饰、星光紫黑主题

## 大屏阶段

| 阶段 | 说明 |
|------|------|
| 报名中 | 舞会序幕，玩家入场报名 |
| 第一次匹配 | 第一轮缘分牵引 |
| 第二次匹配 | 第二轮缘分牵引 |
| 最终匹配 | 曲终配对 |

后台可手动切换阶段，系统匹配后也会自动推进到下一阶段。

## 规则

| 操作 | 灵石 | 说明 |
|------|------|------|
| 报名 | 999 | 凭门票入场，匿名 |
| 确认舞伴 | 1314 | 双方各自扣费，双方都确认后生效 |
| 解除舞伴 | 1111 | 单方扣费即可解除，已投入灵石不退 |
| 投入灵石 | 自定 | 双方合计达到任务解锁值，即解锁该任务 |

- 灵石费用一经缴纳不退
- 初始灵石 10000
- 解除后可再次进入匹配队列

## 文件说明

- `index.html` — 用户页（验票报名 + 舞会大屏 + 确认/解除舞伴 + 灵石共池）
- `admin.html` — 管理后台（白名单、玩家、婚配、任务、阶段）
- `style.css` — 紫黑华丽主题样式
- `config.js` — 配置（仓库地址、Token、管理员密码、费用）
- `data.js` — 数据层（GitHub API 读写 + 缘分匹配算法）
- `data.json` — 游戏数据（白名单、玩家、配对、任务、阶段）

## 安全提示

`config.js` 中的 GitHub Token 会暴露在前端代码中。建议使用**细粒度 Token**（仅允许访问本仓库 contents），并定期更换。
