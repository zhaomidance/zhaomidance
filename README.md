# 🎭 蒙面舞会 · 婚配玩法

多人在线匿名婚配匹配网页，可直接在 QQ 内打开。**纯前端实现，数据存储在 GitHub 仓库，无需后端服务器。**

## 架构

- **前端**：GitHub Pages 静态托管（两个页面）
- **数据存储**：仓库内 `data.json` 文件，通过 GitHub Contents API 读写
- **无需后端、无需信用卡、无需第三方服务**

## 页面

| 页面 | 地址 | 说明 |
|------|------|------|
| 用户页 + 大屏 | https://zhaomidance.github.io/zhaomidance/ | 报名、舞会大屏、查配对结果、婚配操作 |
| 管理后台 | https://zhaomidance.github.io/zhaomidance/admin.html | 查看全部、开始匹配、灵石/任务管理 |

## 功能

- ✅ QQ 号自动获取（QQ 内打开）+ 本地缓存，回来不用重填
- ✅ 报名为弹窗卡片：二字马甲 + 性别（男/女）+ 许愿对象偏好 + 自我描述
- ✅ 报名入口与大屏同页：待匹配舞伴按男/女分列展示，实时人数统计
- ✅ **缘分匹配算法**（非骰子）：参考双方"许愿"与对方"自我描述"的关键词契合度，全局贪心配对，支持十几人同时匹配
- ✅ 已匹配区大卡片展示：名字、缘分值、双方许愿
- ✅ 大屏阶段：报名中 → 第一次匹配 → 第二次匹配 → 最终匹配（后台可切换）
- ✅ 锁定 1314 / 离婚 1111 / 强制解除 5555
- ✅ 任务在匹配成功后统一展示（全体婚配共享）
- ✅ 后台查看全部真实信息（QQ、性别、灵石、状态、许愿、自述）

## 大屏阶段

| 阶段 | 说明 |
|------|------|
| 报名中 | 舞会序幕，玩家入场报名 |
| 第一次匹配 | 第一轮缘分牵引 |
| 第二次匹配 | 第二轮缘分牵引 |
| 最终匹配 | 曲终配对 |

后台可手动切换阶段，系统匹配后也会自动推进到下一阶段。

## 管理员密码

后台默认密码：`zhaomidance2024`（可在 `config.js` 修改）

## 规则

| 操作 | 灵石 | 说明 |
|------|------|------|
| 报名 | 999 | 进入匹配队列，匿名 |
| 锁定 | 1314 | 锁定婚配关系 |
| 离婚 | 1111 | 申请离婚，需对方同意 |
| 强制解除 | 5555 | 单方面解除，无需同意 |

- 灵石费用一经缴纳不退
- 一轮婚配解除后，需重新报名开启新一轮
- 初始灵石 10000

## 文件说明

- `index.html` — 用户页（报名弹窗 + 舞会大屏）
- `admin.html` — 管理后台
- `style.css` — 紫黑华丽主题样式
- `config.js` — 配置（仓库地址、Token、管理员密码）
- `data.js` — 数据层（GitHub API 读写 + 缘分匹配算法）
- `data.json` — 游戏数据（玩家、配对、任务、阶段）

## 安全提示

`config.js` 中的 GitHub Token 会暴露在前端代码中。建议使用**细粒度 Token**（仅允许访问本仓库 contents），并定期更换。
